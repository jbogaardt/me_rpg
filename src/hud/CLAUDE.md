# src/hud (HTML overlays)

Detail moved out of the root `CLAUDE.md` (which has the layers, commands, procedure and conventions); words such as "above" or "below" inside these bullets refer to this file or the map in the root. Keep the bullet for a feature up to date in the same change.

- **Map overlay (solo and co-op)** — `src/hud/MapOverlay.ts` (markup `#map-overlay` in `index.html`): in any open-air zone (rooms have none) the HUD shows an `M` button (`data-key="KeyM"`, so touch works) and the M key toggles a semi-transparent map of the zone you are in (`setZone` repaints it when you cross into another; the world keeps running, it never takes pointer input). **It fills in as you explore**: `src/map/explored.ts` (Pixi-free, tested) keeps an `Explored` bitmap per zone in the scene's `Atlas` (by zone name; lives for the game, not saved) and every player in the zone you are in reveals a disc of `REVEAL_RADIUS` (10) cells around them each frame; unseen cells are transparent, and a neighbouring biome's cells (surface `beyond`) are always the dark background. While online the map also has a pin for you and one per friend in that same zone, each in that player's colour. It is local: each client reveals from the players it can see (a guest only knows those in its own zone), nothing is sent, so there is no protocol change. The terrain pixels (`minimapPixels(data, explored.cells)`) and the world→percent mapping are in `src/map/minimap.ts`; the image is painted on a detached canvas (at most every 400 ms while the map is open and still growing) and shown as an `<img>` so the page keeps a single `<canvas>` (the smoke tests rely on that). `OverworldScene` calls `setAvailable(!indoor)` every frame, so entering a room closes the map.
- **HTML overlays** (`src/hud/`; markup in `index.html`, styles in `src/ui.css`): `Hud.ts` (HP/MP bars), `Dialog.ts` (`#dialog`; tapping it advances; `layout()` keeps it clear of the touch controls), `Menu.ts` (pause menu: Status / Inventory / Controls / Online, plus Trade while online, with Credits as a lone tab in the bottom-left corner; the Online tab is `Multiplayer.ts`, which only drives the `Session`) and `MapOverlay.ts` (the co-op map, below) and `Loading.ts` are DOM rather than Pixi so text stays sharp on phones and can use safe-area insets.
- **UI look**: Lamoot's RPG GUI kit (CC-BY 3.0, credited in CREDITS.md). `tools/ui/cut-gui.ts` cuts pieces from `art/rpg_gui_v1/RPG_GUI_v1.png` into `src/ui/` (bundled by Vite via `ui.css`): gold frames used as `border-image` on `.panel` (`.thin` variant), `.wood`/`.paper` backgrounds, plank tabs, square buttons, D-pad arrows. Fonts: Cinzel (titles) and Crimson Text (body) from Fontsource. Reuse these classes for new UI rather than inventing new styles.
